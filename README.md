# Vanina Balbastro — portafolio

Sitio de portafolio (UX/UI + fullstack) con cinco productos navegables.

**Posicionamiento:** diseño de interfaz y desarrollo, trabajo actual en **Grupo Penna / Comcam**, e IA aplicada a flujos reales.

Live (cuando se publique en Netlify): desplegar esta carpeta.

## Arranque

```bash
npm install
npm run dev
```
